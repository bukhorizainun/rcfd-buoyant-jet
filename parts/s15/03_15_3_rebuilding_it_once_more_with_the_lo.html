15.3 — Rebuilding it once more, with the local-diffusivity field on board

The rebuilt database of §15.1 had one gap of its own. It never stored the local-diffusivity field, so every replay on it had to fall back to the global face-swap. We rebuilt it once more, with the recorder writing that field frame by frame, the same 600-frame recipe as always. We checked the recording before using it: the preparation run reproduces the reference heat-loss CFD digit for digit in the mean-temperature trace (303.2175 K at $t = 494$ s in both files). So this database holds the correct cooling flow and supports the local-diffusion base that §9.3 anchored.

A cooling-flow database needs one extra piece of bookkeeping. Even with the replay's heat-loss term switched off, a replay on this database ends $1.10$ K colder than the adiabatic-base replay. The recorded motion exports heat differently all by itself. So every run below carries two shares. The total share measures all its cooling against the fixed adiabatic-replay end state, the way the trial of §14.1 counted. The fair share subtracts the database's own no-loss drift first, the way §15 counted, so it isolates what the wall-loss path adds.

Read the plain row first, because it settles the question §15 left open. With the local-diffusion base the rebuilt database now captures $35\%$ in total, against $29\%$ on the adiabatic database. So the recorded cooling flow does help. But the split shows how it helps. Eleven points come from the flow's own export, and the fair share, $25\%$, still sits below the adiabatic $29\%$. The flow that was born under cooling moves part of the heat out before the wall term can take it. So the rebuild changes where the cooling comes from more than how much of it arrives. That is §15's lesson restated with better numbers.

The rows below the plain replay all sit below it, every one of them. That is the point of the table. Sharpening rearranges heat the replay already holds, so measured as captured cooling it can at best cost nothing, and here it costs something. The parts that follow read the family in detail and then ask what the ranking is worth, because the cooling it is being scored against turns out not to be what the case declares.

Before the detail, one figure fixes what the percentages actually mean, since every number in this part is a percentage and it is fair to ask where each one is measured. The recovery is a distance between two fixed temperatures. The plain replay ends at $307.62$ K and counts as $0\%$: it has captured none of the heat-loss cooling beyond what the filling phase already gave. The CFD heat-loss run ends at $298.98$ K and counts as $100\%$. The gap between them, $10.19$ K, is the cooling there is to capture. Any run's recovery is just how far its own end temperature has moved from the $0\%$ mark toward the $100\%$ mark, as a fraction of that gap. So a run halfway across has captured half the cooling.
